# Kafka

## Overview
This service creates and manages an Apache Kafka cluster on AWS. It includes automated provisioning of Kafka brokers, Zookeeper nodes (if required), IAM roles, security groups, and monitoring with CloudWatch. The module supports optional features such as EBS volumes for storage, encryption, and VPC integration for secure communication.  
Kafka is a distributed event streaming platform used for building real-time data pipelines and streaming applications.

## Features
- Deploy a Kafka cluster with configurable number of brokers.  
- Optionally create and manage Zookeeper nodes (or integrate with an external Zookeeper / KRaft mode).  
- Create IAM roles and policies for Kafka clients and brokers.  
- Configure security groups to allow ingress and egress traffic on custom ports (default: 9092).  
- Optionally allocate Elastic IPs or private IPs for brokers.  
- Support for EBS volume creation, mounting, and encryption for Kafka storage.  
- Hardened instances with auto-update, fail2ban, and logging agents.  
- Send logs and metrics to CloudWatch for monitoring and alerting.  
- Pre-configured CloudWatch alarms for broker health, CPU, memory, and disk utilization.  
- Support for TLS/SSL encryption and SASL authentication for secure communication.  
- Manage Kafka topics and access controls via IAM and configuration files.  
- Integration with VPC, private subnets, and security groups for network isolation.

### Core Concepts
- **How do I scale my Kafka cluster?**  
  Increase or decrease the number of brokers by updating the module configuration.  

- **How do I configure Kafka topics?**  
  Use provided scripts or Terraform resources to manage topics, partitions, and replication.  

- **How do I secure Kafka communication?**  
  Configure TLS certificates and SASL authentication using IAM roles and policies.  

- **How do I monitor Kafka?**  
  CloudWatch integration provides metrics such as broker availability, partition health, and consumer lag.
