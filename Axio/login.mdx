## Overview

The Login page serves as the gateway to the Axio platform, providing users with secure and seamless access to infrastructure management capabilities. By integrating with trusted identity providers, Axio simplifies authentication while maintaining enterprise-grade security standards.

---

## Why Axio Authentication?

Axio is designed to help platform teams, DevOps engineers, and cloud administrators securely access infrastructure resources without the complexity of managing separate credentials.

Key benefits include:

- Secure authentication through trusted identity providers
- Centralized access to all platform capabilities
- Simplified user onboarding and access management
- Support for enterprise Single Sign-On (SSO)
- Improved security and governance

---

## Supported Identity Providers

Users can authenticate using their organization's preferred identity provider:

- GitHub
- GitLab
- Google
- Microsoft Azure AD

This approach enables organizations to leverage existing identity management systems while providing a familiar login experience for users.
