# Projects

Projects provide the foundational organizational layer within Axio. They help teams group related infrastructure resources, environments, and deployments under a single logical unit, making infrastructure management more structured, scalable, and easier to manage.

## Overview

As infrastructure grows, managing resources individually becomes increasingly complex. Projects help organize infrastructure into manageable units that align with applications, services, teams, or business domains.

Each project acts as a container that groups related stacks and deployment workflows, providing a centralized location for infrastructure management.

Projects help teams:

- Organize infrastructure logically
- Separate environments effectively
- Improve collaboration across teams
- Simplify resource management
- Maintain better operational visibility

Projects serve as the organizational layer between users and infrastructure resources.

A typical structure consists of:

- A Project
  - Development Stack
  - Staging Stack
  - Production Stack

This hierarchy enables teams to manage infrastructure consistently across multiple environments while maintaining clear separation between workloads.

---

## Creating a Project

Creating a project is straightforward:

1. Navigate to **Projects** from the sidebar.
2. Click **Create Project**.
3. Enter the project name and description.
4. Select the desired environment.
5. Save the project.

Once created, the project becomes available for stack creation and deployment workflows.

---

## Managing Projects

The Projects page provides a centralized view of all available projects.

Each project card displays:

- Project Name
- Description
- Environment
- Available Actions

Users can easily manage project configurations and track infrastructure organization from a single location.

---

## Search Projects

As the number of projects grows, quickly locating the correct project becomes important.

The search functionality allows users to find projects based on:

- Project name
- Description
- Environment

This helps improve navigation and operational efficiency across large-scale deployments.

---

## Project Actions

### Edit Project

Update project details whenever requirements evolve.

Common updates include:

- Project name
- Description
- Environment information

### Delete Project

Projects that are no longer required can be removed from the platform.

> Before deleting a project, ensure any associated stacks and resources have been reviewed.

---

## Benefits of Using Projects

### Better Organization

Group related infrastructure resources under a common management boundary.

### Environment Separation

Maintain clear separation between Development, Staging, and Production environments.

### Improved Collaboration

Enable teams to work within well-defined infrastructure structures.

### Simplified Operations

Manage stacks and deployments more efficiently through centralized organization.

### Enhanced Visibility

Gain a clear overview of infrastructure resources across teams and environments.

---

## Why Projects Matter

Projects provide the structure needed to manage infrastructure at scale. By grouping related stacks and resources together, teams can maintain consistency, improve governance, and simplify day-to-day operations.

Whether managing a single application or a large multi-team environment, Projects help establish a clear organizational framework for infrastructure management within Axio.
