## What Is Axio?

Axio is a platform that simplifies **Terraform infrastructure management** by providing a self-service interface for deploying and managing infrastructure stacks. It allows teams to import Terraform modules from Git repositories, configure variables, and execute Terraform workflows through an intuitive web UI.

With Axio, platform teams can create reusable Terraform modules while developers can easily deploy infrastructure without directly interacting with Terraform CLI commands.

Axio helps organizations implement **Infrastructure as Code (IaC)** practices with better visibility, automation, and control.
