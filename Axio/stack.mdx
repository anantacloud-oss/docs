# Stacks

Stacks are the core deployment units within Axio. They connect reusable modules from the Registry with projects, environments, and cloud providers, enabling teams to provision and manage infrastructure in a consistent and automated manner.


## Overview

A Stack represents a deployable infrastructure configuration. It combines infrastructure code, provider settings, variables, and deployment workflows into a single manageable unit.

Stacks allow teams to standardize infrastructure deployments while maintaining flexibility across different projects and environments.

With Stacks, organizations can:

- Deploy infrastructure consistently
- Manage multiple environments
- Track deployment status
- Reuse approved modules
- Simplify infrastructure operations

- Deployment State

Together, these components create a complete infrastructure deployment workflow.

---

## Creating a Stack

To create a new Stack:

1. Navigate to **Stacks** from the sidebar.
2. Click **Create Stack**.
3. Select a Project.
4. Choose a Module from the Registry.
5. Configure provider settings.
6. Define environment variables.
7. Save the Stack.

Once created, the Stack becomes ready for deployment operations.

- Stack Name

## Deployment Lifecycle

Stacks move through a deployment lifecycle that helps teams track infrastructure changes and operational status.

Common states include:

### Running

Infrastructure is successfully deployed and operational.

### Pending

Deployment is waiting for execution or approval.

### Failed

Deployment encountered an error and requires attention.

### Archived

The Stack is no longer actively managed but remains available for reference.

## Why Stacks Matter

Stacks are the operational foundation of infrastructure deployments within Axio.

They provide a structured way to deploy, manage, and monitor cloud resources while ensuring consistency, governance, and scalability across teams and environments.

By combining Projects, Registry Modules, and Cloud Providers, Stacks enable organizations to efficiently manage their infrastructure lifecycle.
