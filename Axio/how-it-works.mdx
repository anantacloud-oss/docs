# How Axio Works

Axio simplifies the Terraform workflow by providing a structured process for infrastructure deployment.

### 1. Import Terraform Modules
- Infrastructure modules are imported from Git repositories such as **GitHub or GitLab**.  
- These modules define reusable infrastructure templates.

### 2. Configure Infrastructure Stack
- Users create a **stack** from a selected Terraform module and define the required input variables such as region, instance type, or network configuration.

### 3. Deploy Infrastructure
   Axio executes Terraform operations such as:

- `terraform plan`
- `terraform apply`
- `terraform destroy`

   These actions provision or modify infrastructure in the target environment.

### 4. Monitor Jobs and Logs
  All Terraform executions are tracked as jobs.Users can monitor:

- Deployment progress
- Execution logs
- Infrastructure status
