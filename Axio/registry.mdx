# Registry

The Registry serves as the central catalog for reusable infrastructure and application components within Axio. It enables teams to discover, organize, and manage standardized assets that can be shared across projects and environments.

## Overview

As organizations scale, managing infrastructure and application assets individually becomes increasingly challenging. The Registry provides a centralized location where teams can maintain approved modules and services for reuse across the platform.

By promoting standardization and reuse, the Registry helps reduce duplication, improve consistency, and accelerate infrastructure delivery.

Key advantages include:

- Centralized asset management
- Improved infrastructure consistency
- Faster deployment workflows
- Better governance and compliance
- Enhanced collaboration across teams

The Registry acts as a shared repository for reusable components used throughout Axio.

It organizes resources into two primary categories:

- Modules
- Services

These assets can then be consumed by Projects and Stacks to build, deploy, and manage infrastructure efficiently.

---

## Modules

Modules are reusable Infrastructure as Code (IaC) building blocks that help standardize cloud resource provisioning.

Instead of creating infrastructure from scratch, teams can leverage approved modules to deploy common infrastructure patterns consistently.

Examples include:

- Virtual Private Clouds (VPCs)
- Databases
- Kubernetes Clusters
- Networking Components
- Security Resources

Modules help reduce operational effort while improving deployment reliability.

---

## Services

Services represent deployable application packages that can be managed through Axio.

They provide a structured way to package, organize, and deploy applications across environments while maintaining consistency and governance.

Examples include:

- Microservices
- Backend APIs
- Frontend Applications
- Worker Services
- Containerized Applications

Services help streamline application deployment and lifecycle management.

---

## Why Registry Matters

The Registry serves as a single source of truth for reusable infrastructure and application components.

By centralizing approved modules and services, organizations can:

- Reduce duplication
- Improve operational consistency
- Accelerate deployments
- Strengthen governance
- Simplify infrastructure management

This approach allows teams to build faster while maintaining quality, reliability, and compliance standards.
