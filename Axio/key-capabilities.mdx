# Key Capabilities

### Terraform Module Management
Import and manage Terraform modules from Git repositories, enabling teams to reuse infrastructure templates.

### Self-Service Infrastructure
Developers can deploy infrastructure stacks without requiring direct access to Terraform or cloud provider credentials.

### Variable Validation
Define validation rules and default values for module variables to ensure correct infrastructure configuration.

### Terraform Automation
Execute Terraform operations such as **plan, apply, and destroy** directly from the Axio interface.

### Job Monitoring and Logs
Track Terraform execution jobs and view detailed logs to monitor infrastructure deployment and troubleshooting.

### Access Control
Manage teams, permissions, and credentials to control who can deploy or manage infrastructure resources.
