# Platform Architecture

Axio connects infrastructure code, governance controls, and deployment workflows into a unified operating model.

## Core Components

- **Registry** — Stores and manages reusable Terraform modules that can be shared across teams. This promotes standardization, reduces duplication, and enables consistent infrastructure deployments.

- **Projects** — Provide logical boundaries for organizing infrastructure resources, environments, and teams. Projects help simplify ownership, access management, and operational visibility.

- **Stacks** — Represent deployable infrastructure configurations built from approved modules. Stacks combine variables, credentials, and deployment settings into a single manageable unit.

- **Credentials** — Securely manage cloud provider access and authentication details. Credentials enable controlled infrastructure provisioning without exposing sensitive information to users.

- **Policies** — Define governance, security, and compliance requirements for infrastructure deployments. Policies help organizations enforce operational standards across environments.

- **Roles and Teams** — Control user permissions and access levels through role-based access management. Teams and roles help ensure that users only have access to the resources and actions relevant to their responsibilities.

- **VCS Integration** — Connect source code repositories from platforms such as GitHub and GitLab. This enables module synchronization, version control, and integration with existing development workflows.

- **Cost Management** — Integrate infrastructure cost estimation into deployment workflows. This helps teams understand the financial impact of infrastructure changes before they are applied.

- **Approval Workflows** — Introduce controlled review and approval processes for infrastructure changes. Approval workflows help reduce risk and improve governance for critical deployments.

- **Identity Integration** — Integrate with enterprise identity providers using OIDC and Azure AD. This enables centralized authentication and simplifies user access management across the platform.

- **Infrastructure Lifecycle** — Infrastructure progresses through a well-defined lifecycle that includes module creation, stack provisioning, review and approval, deployment, monitoring, and continuous management. This ensures infrastructure changes are delivered in a controlled, repeatable, and governed manner.
