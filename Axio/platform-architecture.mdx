# Platform Architecture

Axio connects infrastructure code, governance controls, and deployment workflows into a unified operating model.

## Core Components

### Registry

Stores reusable Terraform modules.

### Projects

Provide logical boundaries for infrastructure ownership and management.

### Stacks

Represent deployable infrastructure configurations.

### Credentials

Securely manage cloud provider access.

### Policies

Define organizational governance rules.

### Roles and Teams

Control access and permissions across the platform.

### VCS Integration

Connect repositories from GitHub and GitLab.

### Cost Management

Integrate cost estimation into deployment workflows.

## Infrastructure Lifecycle

Infrastructure moves through a consistent lifecycle:

1. Module Creation
2. Stack Creation
3. Review and Approval
4. Deployment
5. Monitoring
6. Continuous Management
