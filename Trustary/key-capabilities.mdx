## Key Capabilities of Trustary

- **Secure Container Registry**  
  Centralized storage for container images and artifacts with enterprise-grade security.

- **Role-Based Access Control (RBAC)**  
  Fine-grained permissions for developers, CI systems, and operators.

- **Project-Based Access Management**  
  Organize repositories using projects and assign user roles per project.

- **Built-In Vulnerability Scanning**  
  Continuous scanning to detect CVEs and prevent vulnerable images from deployment.

- **Policy-Based Image Replication**  
  Automatically replicate images across registries using rules based on tags, repositories, or labels.

- **Enterprise Authentication**  
  LDAP, Active Directory, and OpenID Connect (OIDC) integration for SSO and centralized identity management.

- **Job Service Dashboard**  
  Monitor, manage, pause, and resume background jobs such as replication and scanning.

- **Garbage Collection**  
  Clean up unreferenced blobs and manifests to reduce storage usage and improve performance.
