# DevOps Foundations Setup Checklist

Follow these steps to set up your DevOps Foundations and components with Gruntwork:

## Step 1: Activate Your Gruntwork Account
Create a Gruntwork account and invite your team members to gain access to Gruntwork resources.

## Step 2: Set Up a Landing Zone
Complete the AWS Landing Zone walkthrough by Gruntwork to implement a best-practice, multi-account setup, ready to be used with DevOps Foundations.

## Step 3: Configure Pipelines Authentication
Set up authentication for Pipelines to enable secure and automated infrastructure management and changes.

## Step 4: Create New Pipelines Repositories
If starting fresh, create new Pipelines repositories.  
Alternatively, you can add Pipelines to an existing repository.

## Step 5: Configure Account Factory
During the Pipelines setup, configure the Gruntwork Account Factory for managing AWS accounts.

## Step 6: Start Using DevOps Foundations
Once set up, you can begin utilizing DevOps Foundations by:

- Building with the Gruntwork Infrastructure as Code (IaC) Library
- Automating the planning and applying of infrastructure changes using Pipelines
- Creating new AWS accounts with Account Factory
- Keeping your infrastructure up to date with Patcher
