## 🚀 Getting Started with Ananta Cloud

Welcome to **Ananta Cloud** — your unified platform for managing, securing, and automating cloud infrastructure across multiple providers.

---

## 1. What is Ananta Cloud?

Ananta Cloud is a powerful platform designed to help organizations **secure and manage their cloud infrastructure efficiently**. It provides a comprehensive set of tools, modules, and automation to accelerate the delivery of scalable, resilient, and compliant cloud environments.

Whether you are managing **AWS, Azure, Google Cloud, or other providers**, Ananta Cloud simplifies infrastructure security and governance with **ready-to-use modules** and **seamless integrations**.

> By using Ananta Cloud, teams can enforce security best practices, automate infrastructure deployments, and monitor cloud environments continuously — reducing risks and improving operational efficiency.

---

## 2. Supported Cloud Providers

Ananta Cloud supports multiple leading cloud platforms, enabling you to secure your infrastructure across various environments. Currently, we offer integrations and modules for:

- **Amazon Web Services (AWS):** Including EC2, S3, IAM, VPC, and more.
- **Microsoft Azure:** With Azure Resource Groups, Kubernetes, Storage, and identity management.
- **Google Cloud Platform (GCP):** Covering Compute Engine, Kubernetes Engine, Cloud Storage, and IAM.
- **DigitalOcean:** For droplets, Kubernetes, and networking resources.
- **Oracle Cloud Infrastructure (OCI):** Managing compute, networking, and database services.

This multi-cloud support ensures you can implement **consistent security policies** and infrastructure management regardless of your cloud vendor.

---

## 3. Key Concepts and Terminology

To effectively use Ananta Cloud, understanding the following key terms is essential:

| **Term**                     | **Description** |
|-----------------------------|-----------------|
| **Infrastructure as Code (IaC)** | Managing cloud infrastructure through configuration files and code, enabling automation and repeatability. |
| **Modules**                 | Reusable, pre-built components that define infrastructure resources or security policies. |
| **CI/CD Pipelines**        | Automated workflows to build, test, and deploy applications and infrastructure changes. |
| **Security Policies**      | Rules and configurations that enforce best practices and compliance requirements. |
| **Scan**                   | Automated checks performed on your cloud environment to detect security vulnerabilities or misconfigurations. |
| **Cloud Provider**         | The platform where your infrastructure runs (e.g., AWS, Azure, GCP). |

## 4. Developer Onboarding Guide

Welcome to Ananta Cloud! Follow these simple steps to get started quickly:

1. **Create an Account**  
   Sign up on the Ananta Cloud portal to access your dashboard and tools.

2. **Set Up Cloud Credentials**  
   Connect your cloud accounts securely by configuring the necessary IAM roles or API keys. Refer to our cloud provider-specific guides.

3. **Install CLI Tools**  
   Download and install the Ananta Cloud CLI to interact with the platform from your local machine or CI/CD pipelines.

4. **Run Your First Scan**  
   Use the CLI or UI to initiate a security scan on your cloud resources. This scan will identify potential risks and provide actionable recommendations.

5. **Deploy Infrastructure Modules**  
   Explore the module catalog to deploy common infrastructure components with built-in security best practices.

6. **Integrate with CI/CD**  
   Connect Ananta Cloud with your existing pipelines to automate scans and compliance checks during your development lifecycle.

7. **Access Documentation and Support**  
   Visit the Docs site for detailed guides, FAQs, and support contact information.

> ✅ By completing these steps, you’ll be well on your way to securing your cloud infrastructure with Ananta Cloud.
