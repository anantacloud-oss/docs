# Supported Cloud Providers

Ananta Cloud supports a wide range of public cloud platforms to ensure flexibility, scalability, and efficiency in your DevOps and infrastructure workflows. Whether you're deploying containers, managing infrastructure as code (IaC), or automating CI/CD pipelines, our platform is designed to work seamlessly across the following providers:

---

## Amazon Web Services (AWS)

Amazon Web Services is one of the most widely adopted cloud platforms, offering over 200 fully featured services. Ananta Cloud enables:

- Integration with AWS IAM, EC2, S3, RDS, Lambda, and more.
- Support for AWS CloudFormation, Terraform, and CDK.
- Secure access control and policy enforcement via IAM roles.
- GitHub Actions workflows tailored for AWS deployments.

---

## Microsoft Azure

Microsoft Azure provides a broad set of cloud services, including those for compute, analytics, storage, and networking.

- Integration with Azure Resource Manager (ARM), AKS, and Azure DevOps.
- Terraform support for Azure-native infrastructure.
- Identity management via Azure AD integration.
- Seamless deployment to App Services, Functions, and VMs.

---

## Google Cloud Platform (GCP)

Google Cloud is a developer-friendly platform built on Google’s global infrastructure.

- Native support for GKE (Google Kubernetes Engine) and Cloud Run.
- Integration with IAM, GCS, BigQuery, and Cloud Build.
- CI/CD pipeline support using GitHub Actions and GCP service accounts.
- Real-time monitoring and logging via Stackdriver integration.

---

## Oracle Cloud Infrastructure (OCI)

OCI provides high-performance computing and storage at a lower cost.

- Support for Oracle Compute, Object Storage, and Networking.
- Terraform provider for OCI infrastructure automation.
- Secure credential management using OCI Vault.
- Ananta Cloud preconfigured templates for Oracle environments.

---

## DigitalOcean

A developer-friendly platform ideal for startups and small teams.

- Simple provisioning of droplets, databases, and VPCs.
- Kubernetes cluster support (DOKS) for containerized apps.
- GitHub Actions integration for streamlined deployments.
- DNS and firewall automation using APIs.

---

## Multi-Cloud Ready

Ananta Cloud is built to support **multi-cloud strategies**, allowing you to:

- Deploy applications across multiple providers.
- Maintain consistent security and governance.
- Automate infrastructure provisioning and deployments using unified workflows.
